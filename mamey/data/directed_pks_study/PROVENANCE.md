# Directed PKS Study scaffold data

This public-tier-safe directory contains the schema, rules, and a redacted AS-XXX example specification for the directed PKS study scaffold.

Private directed studies can be represented by the same schema in private/merged outputs, but public CODE/SID tiers must not ship literal private strain identifiers.

Purpose: validate user-specified PKS/polyene/macrolide functional groupings, explicit background-cluster exclusions, comparator-context wording, full 20-section Mode B heading requirements, and figure-quality policy.

This scaffold does not run BLASTP, HMMER, DIAMOND, scoring changes, or figure rendering.
