# Sapote-Mamey Multi-Cohort Comparison Toolkit — portable standalone suite

A **stdlib-only** software suite that turns already-sealed Sapote-Mamey package/roster artifacts into
reader-side deliverables (per-BGC protein rosters, novelty boards, strain dossiers, interactive widgets,
AS-vs-SID comparisons, MLSA tree figures, a deduplicated genome pool). Shipped **with** the v9.7.349 CODE
bundle for portability; it is a **companion deliverable suite**, kept separate from the engine `tools/`
and never touching scoring, gates, or sealed packages.

## Quick start (no install — pure Python 3 stdlib)
```bash
python deliverable_tools/cohort_tools.py            # catalog of every tool, by category
python deliverable_tools/cohort_tools.py doctor     # where python/pandoc/GToTree/BLAST/BiG-SCAPE live
python deliverable_tools/cohort_tools.py <tool> -h  # a tool's own help
python deliverable_tools/cohort_tools.py <tool> …   # run it
```

## The front door does three things
1. **Registry** — `cohort_tools.py` catalogs each tool (name → one-line purpose, read from its docstring)
   and dispatches to it. Full list: `TOOLS_INDEX.md` (auto-generated by `cohort_tools.py index`).
2. **Registry of registries** — `cohort_tools.py doctor` probes the shared toolchain and reports where each
   capability actually is. The #1 gotcha it solves: a tool that *exists* but isn't on bare PATH — e.g.
   **pandoc is `Tools/bin/pandoc`, not bare `pandoc`**, and the science python (matplotlib/pandas) is
   `Tools/bin/python3`, not the Framework `python3` that a login shell finds first. Set `SAPOTE_ROOT`
   if your workspace root differs.
3. **Dispatch** — runs any tool standalone so the suite is one program, not a pile of scripts.

## Portability note
Some tools default to workspace-relative input paths; pass explicit `--strain`/paths when running
outside the original workspace. Figures/Word/PDF conversion use the project toolchain surfaced by
`doctor` (matplotlib via the science python; markdown→docx/pdf via pandoc).

## Claim safety
Class-level capacity/context only. These tools re-project existing evidence; nothing here establishes
compound identity, production, activity, or novelty. Similarity ≠ identity. "singleton/AS-private" are
statements about the panel, not the organism. Judgment deferred.
