# Start here

This compatibility page is no longer a separate set of instructions.

- Human readers start at the [README](../README.md).
- Coding assistants read the shared [AGENTS contract](../AGENTS.md).
- At the command line, run `python mamey_run.py start` from the extracted bundle root.
- Use the [current document index](../CURRENT_DOCS_INDEX.md) to find the maintained guide for a specialist workflow.
- Before launching or resuming GToTree, BiG-SCAPE, or another companion process, read
  `docs/LLM_COMPANION_TOOL_PROTOCOL.md` ([open it here](LLM_COMPANION_TOOL_PROTOCOL.md)).

The generated [command catalog](COMMAND_CATALOG.generated.md) is a reference for all commands,
including specialist and compatibility commands. It is not another onboarding path.
