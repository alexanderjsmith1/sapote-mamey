# Write from the evidence

Turn a selected result into figures, captions and short findings you can review.
You need the question, the packages or saved analysis outputs, and any metadata
used in the comparison. A Mode B card is optional for this task.

## Choose the question

Write one sentence saying what you want to learn. List the strains or loci,
what each row represents, and the comparison. For each source, save its path
and checksum. Identify a locus as **strain / full node-or-contig / region / BGC
alias**, copied from one source record.

Read the existing manifest, issue log and inventory before rerunning extraction.
[Read your results](READING_YOUR_RESULTS.md) explains those files. If a figure
command changes package files, use a working copy and keep the original.

## Choose the figures

For each figure, record its ID, question, source table, calculation and included
rows. Show whether it covers all regions, a subset or one representative per group.
Keep missing and omitted panels on the list with a reason.

Use the [figure guide](FIGURES_START_HERE.md) to choose the bundle's renderer.
External trees and family analyses need their own completed outputs before they
can be plotted. For every observation, note the value and units, exact source
row/field, calculation, interpretation and linked figure. Include the numerator
and denominator after exclusions. Keep unavailable measurements separate from zero.

## Draft the text

Write two to four sentences stating what was measured, how, the main result
and the unresolved question. You can ask an assistant for **Power statements**
as writing material. Keep counts traceable to their source rows; describe a
disagreement between channels before explaining it.

Write captions from the actual plotted data. Write Methods from the saved
commands, versions, settings and input selection for that run. If a detail is
missing, leave it marked for recovery instead of substituting the current tool
version. Include the caption-method fields in the [house rules](FIGURE_HOUSE_RULES.md)
and [preflight manual](../wiki/Figure-Factory-Preflight-and-Methods-Manual.md).
Keep work logs separate from the reader caption.

## Check the result

Compare the plotted values, ordering and denominator with the selected source
rows. Look at every image at its delivery size for clipping, labels, units and
legend errors. Run the figure guide's checks and keep their output.
If a panel fails, save the error and correct it in a new review folder.

Keep one index linking each planned figure to its current image, plotted data,
script/configuration, caption, Methods text and checksums. Record which checks
passed and what remains missing. Include the requested image formats and any
omitted formats. A script that redraws saved tables should say so; name the
external analysis and environment separately when reproduction needs them.

Before sharing a public archive, inspect its actual contents for private data,
comments and local paths. Verify public accessions and any type-material label
from their deposited records. Review the wording before using it in a manuscript.
The [deliverable contract](DELIVERABLE_CONTRACT.md) describes the selected files;
[portable evidence roots](PORTABLE_EVIDENCE_WORKSPACE.md) explain how to link a
larger project without moving its original data into the application.

Example request: “Use the reviewed package at runs/EXAMPLE/package to explain the
main result. Give me the selected figures with their source tables and scripts,
Power statements, Methods facts and the questions that remain.”
