# Folder organization and patch author orientation

This cut establishes a shared directory layout for subsequent patches. Start with README.md
for human use and AGENTS.md for all assistants. CLAUDE.md is a generated byte-identical alias.
There is no separate Claude or ChatGPT operating policy.

## Paths that changed

- `games/` is now `debugging_modules/`.
- Setup and supporting prose live in `docs/`, including INSTALL.md, PREREQUISITES.md,
  PLAYBOOK.md, FIGURES_START_HERE.md, and the TIER documentation.
- Supporting install helpers and templates live in `bundle_support/`; there is no `meta/` folder.
- The seven old assistant entry files were consolidated. Their shared instructions are in
  AGENTS.md; the session capability inventory is in `docs/BUNDLE_CAPABILITIES.md`.
- Release stamps, pyproject.toml, mamey_run.py, bootstrap.sh, and generated release manifests
  remain at the bundle root. Runtime package data remains under `mamey/data/`.

## Authoring the next patch

Extract the exact sealed ZIP, record its SHA-256 and live `mamey_run.py start` identity,
and prepare a separate working copy. A version number alone does not identify an unsealed tree.
Read CURRENT_DOCS_INDEX.md and trace actual readers before moving a path or editing generated content.

Rebase old-layout patches by intent. Preserve the original patch, map its changed paths to this
layout, reconcile generated-contract changes, and emit a fresh diff with its own baseline receipt.
Do not force a patch with fuzz or restore removed front doors simply to make it apply.
Run affected tests and the release checks required by CUT_PROTOCOL.md for the final composition.

## Behavior changes

The package inspector preserves full locus identity in text and JSON and refuses incomplete,
conflicting, or duplicate identity. JSON adds strain, region, and exact_locus while preserving
existing score and locator fields. Consumers of old incomplete boards must resolve source
identity before retrying; filters cannot hide an invalid row.

Legacy pipeline tests use an admitted synthetic fixture where it exercises the same output
contract. The domain-evidence test still requires external evidence via SAPOTE_TEST_REFERENCE_ROOT;
missing evidence remains an explicit skip. Synthetic pipeline success is not biological validation.

Tree reports now state when branch checks did not run. External-command failures in the reviewed
phylogenetic helpers and gate wrappers are no longer interpreted as successful empty results.
Optional hook scripts are available under hooks/; see OPTIONAL_HOOKS.md for manual wiring.

## Additional bounded repairs

The majority-read command now uses the existing canonical dated-output overwrite guard and accepts an explicit force option. BLASTp ingest writes HSP alignment length consistently in repository and rollup files; unknown query length and coverage stay blank. Asset lookup retains five-column rows missing only a trailing note with a warning. Inspector admission requires the native Strain field as well as the other identity fields.

After upgrading an existing assistant installation, inspect any locally configured SessionStart hooks for retired startup filenames. Anchor bundle discovery on the local launcher and shared contract, and verify both flat and nested extracted layouts. Bundled hooks do not update host settings automatically.
