# Standalone protein space and reference match explorer

`tools/protein_space_standalone.py` packages an existing enriched viewer and retained comparison catalog into two independent single-file HTML tools. It performs no sequence analysis, ordination, reference search, figure redraw or inferential test. It does not change the bundle's extraction workflow or automatically run during a genome-mining job.

Required inputs are an enriched `codex.protein_space.enriched.v1` viewer and its source-bound comparison catalog. Linked inputs must retain their declared per-strain `data/regions` and `data/reference` assets. Already standalone inputs can be repacked from their embedded payloads. Templates, the shared reference reader, pinned Plotly 2.27.0 and the existing font files are shipped under `tools/protein_space_viewer_assets` and `assets/protein_space_vendor`.

```sh
python3 tools/protein_space_standalone.py \
  --viewer /path/to/enriched/viewer/index.html \
  --catalogue /path/to/catalogue/index.html \
  --viewer-out /path/to/new/Protein_Space.html \
  --catalogue-out /path/to/new/AS_Reference_Matches.html \
  --receipt /path/to/new/STANDALONE_BUILD_RECEIPT.json
```

Existing outputs are refused unless `--replace-candidate` explicitly identifies them as derived candidates. Keep original input evidence immutable. The builder records input, vendor and output SHA-256 values and verifies that every plotted point is unchanged. Each HTML can be moved independently; it requires no server, CDN, sibling asset folder or companion HTML. A current browser supporting `DecompressionStream` is required.

The protein viewer contains all saved layouts and source-region CDS detail available in its input. The reference explorer offers cohort summaries, numeric display filters, sorting, comparison/locus/coverage views, bookmarkable filters and exports of filtered comparisons and complete reference-gene rows with available annotations. All reference rows are retained, including focal-region genes, flanks, other contigs and saved-search not-found rows. Original source map graphics are referenced by path and hash; they are not embedded or regenerated by this tool.

“Core” refers to the focal antiSMASH region, not only biosynthetic-core enzyme roles. Off-core homology, split candidates and concentrated partners do not establish physical linkage. Source STRONG labels, assembly holds, repeated protein assignments and missing/not-queried states remain explicit. Exact strain/contig/locus/protein-length annotation matches do not independently rebind the original alignment sequence. Display means and filters are descriptive; there is no new acceptance score or genus-adjusted statistical result.

The software and font licenses are retained in the vendor folder and embedded in the HTML. `VENDOR_MANIFEST.tsv` pins the asset bytes. Plotly is the input viewer's existing version; no renderer substitution or publication-figure compliance is implied.
