# Start with your file

Choose the guide for the file you have. Each one gets you to a useful result
without installing every optional tool.

- **Code ZIP:** [set up the program](reader/02_INPUTS_AND_SETUP.md).
- **antiSMASH result ZIP:** [run one extraction](reader/01_FIRST_RUN.md) to make
  the region list, workbook and package.
- **Complete_Package ZIP:** [open the saved result](reader/03_READ_RESULTS.md).
- **Failed run:** [find the error and recover](reader/04_RECOVERY_AND_LIMITS.md).

A genome FASTA needs antiSMASH analysis first; Mamey reads the result ZIP.
Keep your original ZIP when extracting or reviewing it.

For a figure, card, comparison or another output, use [Choose a task](USER_TASK_ROUTER.md).
The [walkthrough](MASTER_WALKTHROUGH.md) also shows how to ask an assistant to run the program.
