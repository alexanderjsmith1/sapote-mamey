# Sapote audit recordkeeping starter kit

## What this kit is

A manual kit for keeping an audit trail. It records nothing on its own. Read
[the protocol](SAPOTE_AUDIT_RECORDKEEPING_PROTOCOL.md), then copy the templates you need:
[instruction compliance](instruction_compliance_matrix_TEMPLATE.csv), [run ledger](run_ledger_TEMPLATE.csv),
[finding ledger](finding_ledger_TEMPLATE.csv) and [decision log](decision_log_TEMPLATE.csv).
A Markdown table with the same fields works too.

Leave the templates unchanged. Point to evidence by path and SHA-256 instead of copying it. The
instruction-compliance template comes with `yes` already filled in for applicability; reset that
column for your own task.

## Retained starter-kit description

This folder starts a new external record-keeping method for Sapote/Mamey audits.

Files:
- `SAPOTE_AUDIT_RECORDKEEPING_PROTOCOL.md`
- `instruction_compliance_matrix_TEMPLATE.csv`
- `run_ledger_TEMPLATE.csv`
- `finding_ledger_TEMPLATE.csv`
- `decision_log_TEMPLATE.csv`

Use it so an audit can be checked without relying on unstated reasoning.
