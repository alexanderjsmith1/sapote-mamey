## Reference material

The [Technical Manual / Encyclopedia](03_Technical_Manual_Encyclopedia.html) is a large reference
built from earlier documentation. Each section notes when it was last checked against the code.
That note, not the bundle label, sets what the section can claim. Check any numerical behavior
against the current engine before you use it as a methods description. The
[wiki currency record](../history/wiki_encyclopedia/Encyclopedia-Currency.md) lists which parts of the
retired wiki volumes were reviewed. The [large-reference entry page](07_LARGE_REFERENCE_ENTRY.md) says how
far to trust each large reference.

[Concepts Q&A](06_Concepts_QandA.md) explains the workflow. The
[run-observations template](05_RunObservations_TEMPLATE.md) records what actually happened in a run.

The [glossary pointer](04_Glossary.md) is kept for older links. It redirects to the main glossary.

For numeric methods, read the Python code you ran and the configuration it recorded. A math
companion page or an old review note does not show that the current engine ran every step it
describes.
