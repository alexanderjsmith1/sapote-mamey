# User guides and reference reading

*Included with bundle v9.7.428 / engine Mamey 1.9.163. Packaging version; content scope is described below.*

For a first analysis, read the [Quick Guide](02_Quick_Guide.md). Use the
[User Manual](01_User_Manual.md) for the wider workflow and [Common Mistakes](../COMMON_MISTAKES.md)
when diagnosing a run. [Glossary](../GLOSSARY.md) is the canonical term reference.
The [current document index](../../CURRENT_DOCS_INDEX.md) links specialist workflows.

## Reference material

The [Technical Manual / Encyclopedia](03_Technical_Manual_Encyclopedia.html) is a substantial
reference compiled from earlier documentation. Its section grounding dates, rather than its
bundle label, determine the scope of its verified claims. Check numerical behavior against the
current engine before using it as a methods specification. The [wiki currency record](../../wiki/Encyclopedia-Currency.md)
records the reviewed portions of the separate wiki volumes.

[Concepts Q&A](06_Concepts_QandA.md) explains the workflow. The
[run-observations template](05_RunObservations_TEMPLATE.md) records what actually occurred in a run.
