# User guides and reference reading

*Included with bundle v9.7.465 / engine Mamey 1.9.181.*

Start with the [task router](../USER_TASK_ROUTER.md). It names the question, the inputs you need and
how far each route goes. Its [JSON companion](../USER_TASK_ROUTER.json) gives the same routes to
assistants.

- For a first analysis, read [Your first run](../reader/01_FIRST_RUN.md).
- For an overview of the program's parts and optional workflows, read
  [What Sapote-Mamey offers](../PRODUCT_MAP.md).
- For a finished package, use [Read one saved package](../reader/03_READ_RESULTS.md).
- The [Quick Guide](02_Quick_Guide.md) maps common tasks to commands and pages, and routes other requests to the task router.
- The [User Manual](01_User_Manual.md) is the manual's table of contents.
- [Common Mistakes](../COMMON_MISTAKES.md) helps when you diagnose a run.
- The [Glossary](../GLOSSARY.md) is the canonical general glossary. Workbook cell codes are in the
  [cell-status glossary](../troubleshooting/CELL_STATUS_CODE_GLOSSARY.md).
- The [current document index](../../CURRENT_DOCS_INDEX.md) links the specialist workflows.
- [Concepts Q&A](06_Concepts_QandA.md) explains the workflow.
- The [run-observations template](05_RunObservations_TEMPLATE.md) records what actually happened in a run.

## Reference material

For formulas, thresholds and where each number comes from, use the [methods reference](../reference/00_README.md).
The [Technical Manual / Encyclopedia](03_Technical_Manual_Encyclopedia.html) is an older, large reference.
Its settings and numbers can be out of date, so check any numerical behavior against the code or the
methods reference before you use it in a Methods section.

For numeric methods, read the Python code you ran and the configuration it recorded.
