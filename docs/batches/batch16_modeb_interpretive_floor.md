# Turn Mode B evidence into an argument

Use this checklist when a draft names genes and domains but does not explain what they contribute to the interpretation. First choose the [current profile](../MODEB_PROFILE_MATRIX.md) and use its emitted titles through the [authoring walkthrough](../MODE_B_USER_WALKTHROUGH.md). The §5/§9/§11/§12/§19 references in the older rubric belong to its twenty-section layout.

The previous text is in [the historical rubric](../history/batch16_modeb_interpretive_floor.md).

## Before writing the final judgment

Read the evidence table alongside each relevant section. Carry the source observation forward, explain the inference, and state what remains unresolved.

- **Biosynthetic logic:** What does the recorded gene/domain architecture support? Connect domain observations to a supported structural hypothesis and explain the comparison. A list of domain names alone leaves the reader to supply the reasoning. Predicted architecture does not demonstrate the molecule produced.
- **Alternatives:** What supports each plausible interpretation, and what would distinguish it from the others? Weigh the available evidence. If no discriminating observation is available, keep the alternatives open rather than inventing an objection or claiming rejection.
- **Product family and tailoring:** Which observations change the comparison with a named reference? Explain the supported consequence and its uncertainty. Broad enzyme-family counts alone do not identify particular modifications. For an admitted search with no match, write “no admissible MIBiG match in the searched reference set” and identify that set; an unavailable search remains unavailable.
- **Ecological context:** What specific finding in a source supports the proposed relevance? Explain the connection and identify the transfer being inferred. A host label or compound-class association does not establish function in this strain. Leave unsupported ecology unresolved.
- **Final judgment:** Summarize the decisive evidence, refer back to the alternatives, and pair the supported interpretation with its claim ceiling. Add confidence/provenance tags to the individual claims rather than assigning one label to the whole story.

## Make each claim traceable

Use **observed** for a fact directly present in a named source, **computed** for a result of a stated deterministic rule, **inferred** for reasoning from those facts, and **assumed** for an explicitly declared assumption. Preserve the actual metric: a KCB aggregate score is not a protein identity percentage. An assumed activity default cannot become a measured result or an individual-locus activity claim.

For each individual locus, keep **strain / full node-or-contig / region / BGC alias** from the bound record. Reference evidence in place by path and SHA-256. An unsupported checklist item should explain the missing evidence; it does not require invented chemistry, ecology or an extra search.
