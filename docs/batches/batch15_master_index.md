# Find a guide from an older batch link

If you arrived here from a numbered batch reference, choose your task below. For the full maintained route, open [Find the right document](../DOCUMENTATION_MAP.md).

The previous text is in [the historical master index](../history/batch15_master_index.md).

## Run an analysis or read an existing package

Start a new analysis with the [Master Walkthrough](../MASTER_WALKTHROUGH.md). If you already have a package, go directly to [Reading your results](../READING_YOUR_RESULTS.md). Use [Common mistakes](../COMMON_MISTAKES.md) when a step fails. These replace the old reading path through undelivered batch03, batch08 and batch05 pages.

## Write an interpretation

Choose your [Mode B profile](../MODEB_PROFILE_MATRIX.md), then follow the [authoring walkthrough](../MODE_B_USER_WALKTHROUGH.md). The [batch16 writing checklist](batch16_modeb_interpretive_floor.md) helps turn evidence into an argument; its old section numbers do not select a current card profile.

For scoring vocabulary, consult the [DAPR framework](../DAPR_CLASS_FRAMEWORK.md) in its stated scope. For split-cluster evidence, use [batch18](batch18_rggmci_split_cluster_guide.md). For literature work, use the [search protocol](../LITERATURE_SEARCH_PROTOCOL.md); its historical section numbering does not change your selected profile.

## Choose a deliverable or hand off work

Use the [deliverable menu](../DELIVERABLE_MENU.md) to choose an outcome and the [deliverable contract](../DELIVERABLE_CONTRACT.md) for the selected handoff. For a new collaborator, begin with [Working with an assistant](../ASSISTANT_USER_GUIDE.md) and the [shared operating contract](../../AGENTS.md). Figure work starts at [Make and review figures](../FIGURES_START_HERE.md). Developers looking up version changes should use [Engine lineage](../ENGINE_LINEAGE.md) and bind the actual source version.

## Resolve an old batch citation

Use the actual filename rather than adding one to an old batch number. The original index used an offset numbering scheme: interpretive floor is batch16, DAPR is batch17, split-cluster review is batch18 and literature is batch19. Several promised pages were never delivered. A reference to a missing page remains missing; use the task routes above rather than inventing a counterpart.
