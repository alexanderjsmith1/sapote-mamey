# SOP-08 — C5 Production Deliverables

This SOP was reserved as an outline and never written. The procedure lives in:

- [Deliverable contract: check a strain or project delivery](../DELIVERABLE_CONTRACT.md)

That page is a checklist for the selected delivery. Deliver the workbook, figures and reports required by the task, and record deferred outputs with reasons. Separately, the chosen run profile can require artifacts even when they are not requested for handoff: `--capped-session` requires its workbook while suppressing the written brief and automatic locus maps (unless maps are explicitly enabled). This page stays so the SOP number keeps pointing somewhere.
