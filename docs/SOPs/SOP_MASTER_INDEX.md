# Standard operating procedures

Each SOP covers one recurring task. Find your task below and open its page. If you are new, start
with [SOP-00](SOP-00_Start_Here_Choosing_Path.md), which tells you which procedure fits the file
you have.

For everything else, use the [current docs index](../../CURRENT_DOCS_INDEX.md) or
[Choose a task](../USER_TASK_ROUTER.md).
