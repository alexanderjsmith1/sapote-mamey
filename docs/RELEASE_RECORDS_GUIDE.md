# Read release and validation records in their actual scope

A source tree, documentation overlay, prepared cut, staged tier and distributed archive are different
artifacts. Keep their exact identities and receipts separate. Reference existing evidence in place
by path and SHA-256. When preparing an authorized change, isolate only the files being modified and record the source baseline.
No file title, changelog entry, tier label or embedded PASS row grants a release or disclosure decision.

| Surface | Owner and purpose | What it does not establish |
|---|---|---|
| [CONTRIBUTING](../CONTRIBUTING.md) | Current contributor workflow; parser/fixtures define actual test scope | That default pytest includes all partitions or tests the operator’s live data |
| [SECURITY](../SECURITY.md) | Reporting/support policy; actual repository settings control a private channel | Enabled reporting, an active contact, automatic sending or universal offline CLI behavior |
| [CHANGELOG](../CHANGELOG.md) | Maintainer-authored version/source history, including candidate entries | Every version released, complete historical test coverage or acceptance of each claim |
| [RELEASES_LOG](../RELEASES_LOG.md) | Partial table updated by `tools/log_release.py` when invoked | A built archive or measured leak result from its supplied labels |
| [RELEASE_MANIFEST](../RELEASE_MANIFEST.md) | Mixed narrative and generated fields; `tools/gen_release_manifest.py` plus declared sync anchors | Current overlay validation or an independently checked external seal |
| [Bootstrap file audit](BOOTSTRAP_FILE_AUDIT.md) | Generated from `bootstrap_contract.yml` by `tools/render_bootstrap_contract.py` | Automatic discovery by every assistant or runtime execution of every displayed stage |
| [ENGINE_LINEAGE](ENGINE_LINEAGE.md) | Maintainer-authored engine behavior history; sync checks an engine-version text pattern when the file exists | Proof of every historical comparison or automatic poolability of new outputs |

## Generated boundaries

Do not hand-edit generated Bootstrap audit content or derived release-manifest totals. Shared
bootstrap blocks belong to `bootstrap_contract.yml`; canonical operating prose belongs to AGENTS.md,
and CLAUDE.md mirrors its complete owner-rendered result. Inspect generated parity through that owner.
The map’s “scanner authority” field is a contract designation, not universal assistant discovery.

`gen_release_manifest.py` updates selected volatile fields from source identity and measured/supplied
suite evidence. Its `--fixed-point` mode mutates the manifest and executes its consumer-test subset;
it is not a read-only documentation renderer or substitute for the externally bound full suite.
`sync_version.py --check` checks declared anchors and an engine-version text pattern in an existing
lineage file; a missing lineage file produces a warning. It does not verify historical paragraphs,
detector formulas or release records. Preserve original receipts when source bytes change rather
than updating a PASS count to make the new source appear accepted.

## Candidate identity and evidence

For the selected archive, read the [release manifest](../RELEASE_MANIFEST.md) for its recorded source
validation and material limits. Then match the archive SHA-256 to the external suite evidence and
seal/owner record. Check a documentation overlay against its own changed-source receipts; the original
archive's PASS row does not validate later edits. Keep a missing or unbound receipt chain as a hold.

An accepted contract digest can be checked against its actual JSON;
that match identifies contract bytes, not an accepted authored card or package.

For a patch review, report the baseline path/hash, changed Markdown files, checks actually run,
source owners, unresolved holds and the current authoritative candidate index. Full package copies,
new installs, test-suite execution, version propagation, logging a release, signing or publishing
are separate operations and require the applicable user scope. Historical scientific examples remain
historical unless independently rebound and reviewed.
