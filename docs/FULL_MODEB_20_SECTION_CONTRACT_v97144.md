The §1–§20 Mode B contract is retired. This page only points to the current pages.

## Read instead

- [MODEB_PROFILE_MATRIX.md](MODEB_PROFILE_MATRIX.md) — choose the profile. Finished cards use
  `FINISHED_FULL48_CURRENT_EVIDENCE` (§1–§48) by default, or the opt-in `current50_v2` (§1–§50).
- [MODE_B_30_SECTION_CANONICAL_TITLES.md](MODE_B_30_SECTION_CANONICAL_TITLES.md) — the §1–§48 title
  list. The `30` in its file name is historical.
- [FULL_MODEB_30_SECTION_CONTRACT_v97150.md](FULL_MODEB_30_SECTION_CONTRACT_v97150.md) — the full48
  contract: required, conditional and optional sections and their predicates.

Those two pages are generated by `tools/regen_modeb_contract_docs.py` from
`mamey/data/mode_b/modeb_full30_corrective_contract.json`. The
[walkthrough](MODE_B_USER_WALKTHROUGH.md) is written by hand.

## What changed from §1–§20

§1–§20 titles and order did not change. The 30-section layout added §21–§30: §28 (Evidence
provenance ledger) and §30 (Experimental decision tree) are always required, and §21–§27 and §29
are conditional. The full48 profile adds §31–§48.

`mamey/validators/modeb_full20.py` still checks the first twenty titles and some obsolete headings
for `mamey/directed_pks_study.py`. It does not verify a whole card. Use `verify-modeb` for that.
