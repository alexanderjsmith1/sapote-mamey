## Artifact-drift rule

A real Mode B card is a written interpretation built from evidence. Tables, FASTA files, PDFs, character counts, and before/after trackers are supporting artifacts, not acceptance evidence. One BGC must pass the prose-first gate before scaling to many BGCs.
