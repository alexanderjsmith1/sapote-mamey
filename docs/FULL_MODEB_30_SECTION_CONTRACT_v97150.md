## Section sub-questions

Named prompts that deepen an existing section (no new section is added). The template emitter renders them for the author; the depth gate treats them as WARN-only.

**§5 — Core biosynthetic logic**
- Committed-step audit: is the class's committed/necessary gateway enzyme actually present (per the class-believability engine, LQ-PATH-01), or is this the named false-positive superfamily the class label over-calls into?
- Minimal-gene-set completeness: is the minimal gene set for this scaffold complete ON THIS CONTIG, or is a core piece most likely an off-contig fragment (fragmentation — cross-check RG-GMCI)?

**§9 — Alternative hypotheses**
- Named-FP alternative: state the specific superfamily / primary-metabolism mis-call this class label is prone to (from the registry / LQ-PATH-01), and weigh it explicitly.
- Fragment alternative: is the more parsimonious reading that this region is a FRAGMENT of a larger known pathway captured mid-cluster? Weigh against RG-GMCI (4A_*).

**§13 — Antibacterial/antifungal relevance**
- Class in Actinobacteria: how common / characterized is this compound CLASS among actinobacterial natural products? (NP Atlas npclassifier class-frequency, LQ-NPATLAS-01 — organism-independent, aggregate only.)
- Class in this genus: what is reported for this class in this genus? — tagged `inferred`/`assumed` and grounded in literature, NOT asserted from NP Atlas isolation provenance (which records origin, not taxonomic distribution).

8. Section 4 contains one contiguous named-match table with exactly one row per independently supplied canonical displayed gene.
9. Sections 5–7 satisfy the explicit scientific-reasoning scaffold; character counts are diagnostics only.
10. Every section §1–§48 has a completeness row naming evidence and predecessor-content disposition.
11. All 14 supporting streams have typed dispositions and historical content loss is reconciled explicitly.
12. Comparator/KCB is treated as similarity, not identity.
13. At least two plausible alternative interpretations are named when evidence permits.
14. Exact product claims are avoided.
15. The next experiment or analysis is specific.
16. A scientist can understand the BGC without opening the CSV.
17. Every first BGC mention uses the four-field display: strain / full node-or-contig / region / BGC alias.
18. Character counts are progress metadata only; never acceptance evidence.
19. Mechanical validation cannot claim release or publication readiness (cap: EVIDENCE_MATRIX_VALIDATED).
