# Figure Factory guides

Start with the [aggregate rendering guide](../FIGURE_FACTORY_NEXT.md) for a runnable synthetic example, configuration,
commands, output files, and R restyling. The [preflight and methods manual](../../wiki/Figure-Factory-Preflight-and-Methods-Manual.md)
covers figure-specific checks. [Optional gallery tools](../OPTIONAL_FIGURE_FACTORY_TOOLS.md)
preview themes and components.

The [progress dashboard pattern](PROGRESS_DASHBOARD_PATTERN.md) describes the reusable operational
telemetry design. Historical repair specifications and source-binding work notes are maintained in
development evidence stores and are not shipped as end-user instructions.

For review handoffs, choose the [paginated queue](../FIGURE_REVIEW_WORKFLOW.md) or the [owner action-plan compiler](../FIGURE_OWNER_REVIEW_WORKFLOW.md) deliberately; their TSV decision schemas differ. For [R redraws](../R_FIGURE_WORKFLOWS.md), retain new artifact bindings rather than reusing the Python receipt. Read each channel's hold/skipped status before interpreting a successful surrounding command.
