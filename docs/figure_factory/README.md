# Figure Factory guides

Start with the [aggregate rendering guide](../FIGURE_FACTORY_NEXT.md). It has a runnable synthetic example, the configuration,
commands, output files and R restyling. The [preflight and methods manual](../../wiki/Figure-Factory-Preflight-and-Methods-Manual.md)
covers checks for each figure. [Optional gallery tools](../OPTIONAL_FIGURE_FACTORY_TOOLS.md)
preview themes and components.

The [progress dashboard pattern](PROGRESS_DASHBOARD_PATTERN.md) describes a reusable design for showing run progress.
Old repair specifications and source-binding work notes are kept in development evidence stores.
They are not shipped as user instructions.

For review handoffs, choose between the [paginated queue](../FIGURE_REVIEW_WORKFLOW.md) and the [owner action-plan compiler](../FIGURE_OWNER_REVIEW_WORKFLOW.md). Their TSV decision formats differ. For [R redraws](../R_FIGURE_WORKFLOWS.md), keep new records for the new files rather than reusing the Python receipt. Read each channel's hold or skipped status before you trust a successful surrounding command.
