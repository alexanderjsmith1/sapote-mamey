# Start with one strain

Retired in v9.7.458 and kept as a record. Settings and commands may be out of date. Current guide: [Start here](../../START_HERE.md).

Open [Start a first run](../../user_guides/FIRST_RUN_ORIENTATION.md) to identify your input and prepare
your program and output locations. Then follow [Your first analysis](../../MASTER_WALKTHROUGH.md)
for the commands, using either the assistant route or the Terminal route.

The first result to inspect is the package the run prints: check its validation findings,
workbook and recorded issues using [Read your results](../../READING_YOUR_RESULTS.md).
If you already have a Complete_Package ZIP, start with that results reader.

A code ZIP supplies the program; a genome FASTA needs upstream antiSMASH processing before
this extraction route. Use the [Quick Guide](../../GUIDE/02_Quick_Guide.md) for evidence-budget choices
and a compact command reference after choosing your route.
