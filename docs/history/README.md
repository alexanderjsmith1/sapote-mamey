# Archived development and release records

These version-stamped patch notes, receipts, release notes and superseded protocols preserve earlier development context. Their commands, candidate decisions and next-cut lists are historical records, not current operating instructions.

Test counts, timings and sign-offs in these files describe their own time. They are not current results.

For current work, use [the current docs index](../../CURRENT_DOCS_INDEX.md), [the Quick Guide](../GUIDE/02_Quick_Guide.md) or [the canonical glossary](../GLOSSARY.md). The [changelog](../../CHANGELOG.md) records release history. Keep historical bodies and their version/source context together; correct current guidance in its maintained owner rather than silently rewriting old results.
