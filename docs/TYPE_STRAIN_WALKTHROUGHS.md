# Moved: recorded public-genome walkthroughs

[The walkthrough record](history/TYPE_STRAIN_WALKTHROUGHS_RECORD.md) holds reported historical results from nine earlier runs on public type-strain genomes. It is a fixed record, not a recipe. Its input archives and run receipts are not bundled, so the results cannot be checked from this repository.

To run a genome yourself, use [Your first run](reader/01_FIRST_RUN.md). To read a result, use [Read your results](READING_YOUR_RESULTS.md).
