# Manual NCBI BLASTP Spot-Check Workflow

NCBI web BLASTP is appropriate for top-lead spot checks, not for bulk annotation of thousands of proteins.

Use manual BLASTP when:

- a small number of proteins from a top BGC need human review;
- a DIAMOND/HMMER result needs sanity-checking;
- a top lead will be discussed in a report or manuscript.

For bulk work, use DIAMOND or MMseqs2-style local searches and import structured output.
