# Bundle support files

Install scripts, the marker registry (the list of gene markers the engine looks for), Pfam accession lists and templates.

- `install_sapote_addons.sh` targets `${PYTHON:-python3}` and verifies imports through that same interpreter. It normally requires a virtual environment; the explicit system-pip override is a separate operator choice. Local wheel resolution runs first. `--online` permits pip-index fallback only for the documented missing-wheel/resolution cases, not every failure. The core group is required; figure/analysis dependencies are best-effort and need their own availability checks. Give an explicit wheel folder when needed. See [installation](../docs/INSTALL.md).
- `install_r_figure_packages.R` installs the R packages the figure tools need, in four groups: `core`, `trees`, `bioassay` and `extras`. Without `--check` or `--from`, it can contact CRAN, Bioconductor and a pinned GitHub archive. `--check` is a non-installing inventory; `--from DIR` selects operator-supplied offline package archives. It prints every package with its group and its installed version or missing state, and exits 2 when a required group is incomplete. Only `core` is required unless you add `--require <groups>`. See [prerequisites](../docs/PREREQUISITES.md#r-figure-stack).
- `registry_inventory_v1.9.4.json` is the marker registry used when registry detection is enabled and activates successfully (`mamey/registry_detector.py`, `mamey/source_scans.py`). Inspect the selected run's active/fallback and degradation states. The name keeps an old engine version number; this shipped file has 156 entries, not necessarily 156 active runtime patterns. `registry_inventory_v1.9.4.csv` is generated from it by `tools/export_registry_inventory_csv.py`.
- `scanner_pfam_35_accessions.txt` and `scanner_pfam_148_accessions.txt` list the Pfam accessions for the two scanner presets (the 35-family and 148-family Pfam sets). `scanner_accession_source_pins.json` holds their hashes. To build the scanner, see [the scanner manifest](../docs/reference/SCANNER_PFAM_MANIFEST.md).
- `project_state_template.json` is a blank project-state template. Copy it for a new project, then fill in or check every field. `bundle_version` names the bundle that shipped it; set it to the bundle you run. Keys that start with `_` are notes on the allowed values and row shapes.
- `deliverable_menu_widget.html` is the deliverable menu, generated by `tools/build_deliverable_menu_widget.py`.

Two folders sit at the bundle root, beside `bundle_support/`. `Wheelhouse/` holds `engine`, `scanners`, `strains` and `validations` subfolders. It has no `hmm/` folder; the scanner HMM is not shipped. `wheels/` holds the build-backend wheels listed in [WHEELS_MANIFEST.md](../wheels/WHEELS_MANIFEST.md).
