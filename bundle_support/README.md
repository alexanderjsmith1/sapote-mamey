# Bundle support assets and provisioning boundaries

Setup scripts, templates, Pfam accession lists and catalog snapshots. Nothing here is analysis evidence.

- `install_sapote_addons.sh` installs Python dependencies into the selected virtual environment. It tries local wheels first; `--online` permits a missing-wheel index fallback. It verifies imports, not functional tool/database admission. Optional figure-stack failures can remain visible while required imports succeed. See [installation](../docs/INSTALL.md) and [companion retrieval/provisioning controls](../docs/447_COMPANION_RETRIEVAL_CONTROLS.md).
- `install_r_figure_packages.R` provisions the R figure packages in four groups: `core`, `trees`, `bioassay` and `extras`. Core is required by default; `--require trees,bioassay` adds selected requirements, and `--require all` requires every group. `--check` reports availability without installing. Normal provisioning can download packages; `--from <directory>` uses supplied local package archives. See [prerequisites](../docs/PREREQUISITES.md#r-figure-stack) for the group list and selected renderer requirements.
- `scanner_pfam_35_accessions.txt`, `scanner_pfam_148_accessions.txt` and `scanner_accession_source_pins.json` are selectors and source pins, not HMM payloads. Model provisioning requires source-bound receipts; see [external data](../docs/EXTERNAL_DATA.md).
- `registry_inventory_v1.9.4.csv/json` are a historical inventory snapshot, not current module/registry counts or release verification.
- `project_state_template.json` is an empty session-state template.
- `deliverable_menu_widget.html` is a populated catalog snapshot, generated by `tools/build_deliverable_menu_widget.py`. Its displayed actions do not execute or authorize a task; registry labels do not establish availability. See [HTML reader names and recovery contracts](../docs/HTML_TEMPLATE_READERS.md).

Uppercase [Wheelhouse](../Wheelhouse/README.md) contains strain/scanner metadata and prototype helpers. Lowercase [wheels](../wheels/WHEELS_MANIFEST.md) contains build-backend wheels. Neither substitutes for the active environment, current receipts or the project owner's release decision.
